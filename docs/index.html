macOS 14+ · 开源工具

多个账户，一个菜单栏。

在 macOS 菜单栏管理多个 Codex 账户。保留独立登录状态、切换项目窗口，并通过项目接力在账户之间继续已有任务。

下载 CodexM ↗阅读项目说明 ↗

需先安装兼容的官方客户端。CodexM 是独立开发的工具，与 OpenAI 无隶属或背书关系，不包含官方客户端。

项目能做什么

独立账户

分别保留账户登录和应用数据，从菜单栏启动、停止和重命名账户配置。

窗口切换

集中查看账户窗口，悬停预览、识别目标窗口并切换到正在进行的项目。

项目接力

预览并整理上下文后继续任务，或通过兼容性检查导入已有任务历史。

开始使用

  1. 支持 macOS 14 及更新版本，Apple Silicon 和 Intel。先安装兼容的官方客户端。
  2. 下载 DMG，把 CodexM 拖入 Applications，启动后选择官方客户端。
  3. 添加账户并在官方客户端内登录。窗口聚焦和预览功能按提示授予辅助功能权限。

完整说明、兼容范围与最新状态见 项目 README。问题反馈请前往 GitHub Issues。
